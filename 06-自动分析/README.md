# 自动分析输出

根目录只保留少量入口文件：

- `最新摘要.md`：自动任务生成的外部阅读入口，只展示各标的四周期动作、成功/失败和组合检查链接。
- `README.md`：本目录说明。

详细产物按类别归档：

```text
06-自动分析/
├── 最新摘要.md
├── 个股/<标准代码>/*.md       # 个股四周期分析（文件名含股票名称）
├── 个股/<标准代码>/charts/*   # 支撑压力/K线/指标图与独立概率扇形图
├── 组合/*.md                  # 持仓、行业和现金约束
├── 回测/<标准代码>/*.md        # walk-forward 与预测评估
└── 归档/*.md                  # 无法识别类型的旧报告
```

`stock auto` 每次运行前会自动整理历史扁平报告；也可以单独执行 `stock organize`。文件只移动、不覆盖已有目标文件。新闻、宏观、回测、回执和任务状态保存在 `.stock-analysis/analysis.sqlite3`，Markdown/SVG 是便于阅读的派生产物。

报告属于运行产物，默认不纳入 Git。分析结论必须同时查看数据日期、质量等级、模型校准状态和失效条件，不应只读取“动作建议”。

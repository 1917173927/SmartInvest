## 一、 盘中决策的三大认知红线（关键概念辨析）

在开始使用任何量化分析或运行命令行命令之前，请个人投资者务必牢记以下三大核心概念的本质区别。混淆这些概念是造成交易失误的最常见原因：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      三大认知红线核心对照矩阵                           │
├───────────────────┬──────────────────────────┬──────────────────────────┤
│ 维度              │ 概念 A                   │ 概念 B                   │
├───────────────────┼──────────────────────────┼──────────────────────────┤
│ 1. 行情价格       │ 盘中实时/延时报价        │ 上一交易日收盘价         │
│                   │ (券商 App 毫秒级五档盘口)│ (本地 SQLite 历史缓存)   │
├───────────────────┼──────────────────────────┼──────────────────────────┤
│ 2. 资金口径       │ 账户总资产 (Total Equity)│ 可用现金 (Available Cash)│
│                   │ (股票市值 + 剩余现金)    │ (证券账户当前随时可买现金)│
├───────────────────┼──────────────────────────┼──────────────────────────┤
│ 3. 指令属性       │ 触发条件 (If-Then 条件)  │ 立即买入建议 (Market Buy)│
│                   │ (跌至击球区时才执行)     │ (看到报告立马冲进去)     │
└───────────────────┴──────────────────────────┴──────────────────────────┘
```

### 1. 盘中实时/延时报价 vs 上一交易日收盘价

- **上一交易日收盘价（本地数据）**：
  SmartInvest 系统在本地 SQLite 数据库中存储的是每日盘后同步的日线行情数据（通常是昨日 15:00 收盘价）。当你未做实时更新直接运行分析命令时，系统看到的是**历史收盘价**。
- **盘中实时/延时报价（券商盘口）**：
  交易时间（09:30–15:00）内，券商 App（如华泰证券、东方财富、同花顺等）界面上跳动的价格是**实时买卖盘五档撮合报价**。
- **🚨 核心红线**：
  **绝不能将本地历史收盘价直接当作当前能够立即成交的现价！**
  在盘中做出任何挂单决策前，必须打开手机券商 App 查看当前的实时真实买一/卖一价格。

### 2. 账户总资产 vs 可用现金

- **账户总资产（Total Capital / Equity）**：
  包含您账户内持有的**所有股票现有市值 + 现金余额**的总和。系统的风控模型（例如设定核心标的最大持仓 20%）是基于【账户总资产】测算该股票允许配置的总金额上限。
- **可用现金（Available Cash）**：
  您当前证券账户中尚未买入任何资产、此时此刻**可以直接用来扣款下单的闲置资金**。
- **🚨 核心红线**：
  系统计算出的建议买入金额（例如：总资产 10 万 × 目标上限 20% = 2 万元）表示该标的建仓完毕后的**理想目标配置额度**。
  如果您的账户目前仅剩 5,000 元可用现金，**严禁通过借款、融资融券或透支去强行买满 2 万元**！请使用下文介绍的 `--capital` 参数，以当前手头真实的可用现金进行精算。

### 3. 触发条件 vs 立即买入建议

- **触发条件（Trigger Condition / If-Then 挂单点）**：
  系统在晨报或测算表中给出的“挂单价 / 触发价”，代表“**如果未来市场价格回踩到这个具有安全边际的点位，才构成合理的建仓条件**”。
- **立即买入建议（Immediate Market Buy）**：
  误以为一看到分析报告，就要在当前价格以市价单立刻全额买进。
- **🚨 核心红线**：
  **“进入分析池”绝不等于“现在立刻买入”！**
  如果标的当前市场价格高于第一档挂单价，现在的正确动作是**耐心等待价格回调**或**在券商 App 预埋条件单**，绝不可市价追高。

## 二、 实盘仓位精算器 stock size 安全使用范式

`stock size` 是专为实盘交易者设计的仓位与挂单测算工具。它能根据投资者的资金规模与风险预算，自动计算出 3 个梯度的挂单价格、建议股数（精确向下取整至 100 股整数手）与极端止损线。

### 1. 自动读取配置与一键测算

如果您已经在 `stock-analysis.toml` 中配置了标的信息，只需直接输入证券代码：

```bash
# 语法：uv run stock size 证券代码
uv run stock size CN:601318
```

- **自动行为**：系统会自动读取配置文件中该标的的定位角色（`role = "core"` 核心资产通常分配 20% 上限，`satellite` 卫星资产通常分配 10% 上限）、估值模型参数以及本地历史技术支撑位，默认以 100,000 元资本金和 2% 风险预算生成三档执行阶梯。

### 2. 使用 --capital 临时覆盖可用资金

当您的实际资金不是 10 万元，或者您只想针对当前账户中剩余的**可用现金**进行测算时，必须使用 `--capital` 参数：

```bash
# 示例 1：当前账户可用现金为 50,000 元
uv run stock size CN:601318 --capital 50000

# 示例 2：小资金投资者测试（如可用资金 20,000 元）
uv run stock size CN:601318 --capital 20000
```

> [!TIP]
> **安全习惯**：永远将 `--capital` 设置为不超过您证券账户当前的【可用现金】余额，防止因资金不足导致券商 App 报单失败或产生透支风险。

### 3. 使用 --price 输入券商实时现价覆盖

在交易时间段内，盘中价格可能已偏离昨日收盘价。通过 `--price` 参数传入您在券商 App 看到的**最新实时现价**，系统将基于真实盘口重新校准第一笔底仓与后续回调支撑阶梯：

```bash
# 示例 1：券商 App 看到中国平安现价为 43.80 元，账户可用资金 50,000 元
uv run stock size CN:601318 --capital 50000 --price 43.80

# 示例 2：自定义该标的目标仓位上限为 15%，单笔最大风险 1.5%
uv run stock size CN:601318 --capital 50000 --price 43.80 --target-weight 0.15 --risk-budget 0.015
```

- **参数组合速查**：
  - `--capital <金额>`：指定本次参与测算的基准资金（元）。
  - `--price <价格>`：指定券商当前实时现价（元），覆盖本地历史缓存价格。
  - `--target-weight <比例>`：自定义该股票在总资金中的最大持仓占比（如 `0.15` 代表 15%）。
  - `--risk-budget <比例>`：单笔交易最大承受回撤比例（如 `0.02` 代表 2%）。

- **🛑 逻辑失效与止损参考线**：当股价跌破该价位时，表明安全边际与技术支撑均已彻底失效，必须严格执行风控清仓。

## 三、 盘中六大状态决策树：现在该做什么 / 不该做什么

在交易时间内，根据券商 App 呈现的**实时价格**与系统计算出的**三档挂单阶梯**，投资者将面临以下六种典型市场状态。请严格对照执行：

```
                           ┌───────────────────────────┐
                           │   查看券商 App 实时价格   │
                           └─────────────┬─────────────┘
                                         │
         ┌───────────────────────────────┼───────────────────────────────┐
         ▼                               ▼                               ▼
  【现价 > 首笔价】              【现价 == 某档挂单价】            【现价 < 止损线】
  (状态 1: 溢价观望)             (状态 2, 3, 4: 触发分批)          (状态 5: 逻辑破位)
         │                               │                               │
  ▶ 严禁追高追涨                  ▶ 严格限价单买入对应手数        ▶ 坚决止损离场
  ▶ 仅设置到价提醒                ▶ 严禁一次性打满全部预算        ▶ 严禁死扛浮亏加仓
```

---

### 状态 1：高于首笔价（溢价观望区）

* **判定标准**：券商 App 实时现价高于表格中的“① 首笔底仓”挂单价格（即尚未进入合理估值安全买入区间）。
* **✅ 现在该做什么**：
  1. **保持耐心，空仓观望**：把手机放一边，遵守交易纪律。
  2. **设置预警/条件单**：在券商 App 中针对该标的设置一条“股价下跌至首笔价时提醒我”的到价预警，或预设一条有效期内的“回踩触达买入条件单”。
* **❌ 现在绝对不该做什么**：
  1. **严禁市价追高**：绝不能因为看着盘面在涨、害怕踏空（FOMO 情绪）而随手市价买入。
  2. **严禁自行上调买入价格**：绝不可擅自修改买入标准。
* **💡 风控提醒**：
  股票市场永远不缺交易机会，缺的只有本金。不买不会亏钱，追高买入直接丧失安全边际。

---

### 状态 2：达到首笔价（首笔底仓触发）

* **判定标准**：股价在盘中正常回调，触及或低于“① 首笔底仓”挂单价格。
* **✅ 现在该做什么**：
  1. **限价单委托**：打开券商 App，选择【普通限价买入】，价格输入首笔挂单价，数量输入表格给出的【建议手数】（如 1 手/100 股）。
  2. **核对可用资金**：确认委托所需资金在可用现金余额之内。
* **❌ 现在绝对不该做什么**：
  1. **严禁一次性打满所有资金（All-in）**：首笔底仓配比仅为 30%，绝不可把计划买三批的钱在第一批全部花完！
  2. **严禁使用市价单买入**：必须使用限价单，避免盘口瞬间滑点造成高价成交。
* **💡 风控提醒**：
  首笔底仓的作用是“建立观察仓位”，后面两档有更便宜的加仓机会。

---

### 状态 3：达到第二档（强支撑回调加仓）

* **判定标准**：股价进一步下挫，触及“② 回调加仓”价格（通常为近端强支撑区间上沿）。
* **✅ 现在该做什么**：
  1. **确认无突发基本面暴雷**：简要查看公司公告，确认无突发违规、业绩断崖式下修或重大诉讼。
  2. **限价单买入第 2 笔**：在券商 App 中按第 2 档建议价格和建议手数下达限价买单（配比 40%）。
  3. **计算持仓均价**：记录前两笔合并后的实际综合持仓成本。
* **❌ 现在绝对不该做什么**：
  1. **严禁因恐慌而放弃执行**：只要基本面没有恶化，达到预定支撑位就是计划内的加仓点，不要受盘面恐慌情绪影响。
  2. **严禁超额加仓**：不可擅自把第 3 档的资金提前挪到第 2 档使用。
* **💡 风控提醒**：
  分批建仓的精髓就在于平摊成本，严格按照系统计划执行才能发挥网格优势。

---

### 状态 4：达到第三档（极限价值底加仓）

* **判定标准**：市场出现深度调整或极端恐慌，股价触及“③ 极限买点”价格（次级纵深支撑带或深度估值安全下沿）。
* **✅ 现在该做什么**：
  1. **执行最后一笔限价买入**：下达第 3 档建议手数的限价买单（配比 30%）。
  2. **完成建仓闭环**：至此，该标的 3 笔阶梯计划已全部执行完毕，总持仓达到预设的目标上限比例。
* **❌ 现在绝对不该做什么**：
  1. **严禁继续追加第四笔、第五笔**：该股票的买入额度已彻底用尽！
  2. **严禁动用非闲置资金或加杠杆**：绝不可动用生活备用金、借款或融资融券补仓。
* **💡 风控提醒**：
  三笔买完后，投资者的唯一任务就是“停止操作，等待市场自我修复或触及止损”。

---

### 状态 5：跌破失效线（硬止损与逻辑破位）

* **判定标准**：股价跌破表格底部的“🛑 逻辑失效与止损参考线”（例如连续两个交易日收盘价低于失效线，或盘中跌破且基本面逻辑逆转）。
* **✅ 现在该做什么**：
  1. **果断止损离场**：在券商 App 中以限价单分批或全部卖出该标的，严格控制最大亏损在预估金额之内。
  2. **记录并复盘**：在交易笔记或 Obsidian 中记录本次逻辑失效原因（如行业政策突变、业绩不及预期等）。
* **❌ 现在绝对不该做什么**：
  1. **严禁死扛浮亏**：绝不能抱着“只要我不卖就没亏”的侥幸心理。
  2. **严禁倒金字塔无底线补仓**：破位之后绝不可越跌越买，避免将单笔小亏损演变成致命的毁灭性爆仓。
* **💡 风控提醒**：
  止损不是失败，而是为了保护本金以参与下一次机会。交易体系必须包含退出机制。

---

### 状态 6：报价过期或数据源获取失败（离线与异常处置）

* **判定标准**：终端运行 `stock size` 提示“没有可用行情缓存”或报错，或者系统显示的日期与当前实际交易日差距很大（数据脱节）。
* **✅ 现在该做什么**：
  1. **以券商 App 官方实时数据为准**：立即暂停依赖命令行输出做交易。
  2. **检查网络并同步行情**：在交易日收盘后或网络正常时，运行数据同步命令：
     ```bash
     uv run stock sync CN:601318
     ```
  3. **运行环境诊断**：若持续报错，运行诊断命令检查数据接口状态：
     ```bash
     uv run stock doctor
     ```
* **❌ 现在绝对不该做什么**：
  1. **严禁依据过期的价格数据盲目下单**。
  2. **严禁在数据质量警告高危时强行交易**。
* **💡 风控提醒**：
  宁可因数据异常错过一次交易，也绝不在信息错误的情况下盲目下注。

## 四、 个人投资者实盘执行五大铁律

为了确保个人投资者在实盘操作中能够长期稳定生存，请在每一次按下交易按钮前默念以下五大铁律：

### 铁律一：严格使用限价单，坚决禁用市价单
- **为什么**：A 股市场在集合竞价（09:15–09:25）以及盘中剧烈波动时，市价单（最优五档即时成交等）极易产生严重的滑点损失，甚至以全天最高价买入。
- **怎么做**：所有买入与卖出，必须在券商 App 中选择**普通限价委托**或**到价条件单**，精确填入系统推荐的具体数值。

### 铁律二：严格分批建仓，拒绝一次性梭哈
- **为什么**：没有人能够精准预测当天的最低点。一次性全额买入等于将容错率降为零。
- **怎么做**：严格遵循 `30% (首笔) → 40% (支撑) → 30% (极限)` 的节奏。没有触发下一档，就绝不提前把子弹打光。

### 铁律三：严格坚守不追涨，宁可错过绝不上套
- **为什么**：追涨是散户亏损最核心的心理根源。买入成本过高会导致稍有震荡就被迫止损。
- **怎么做**：价格只要在第一档挂单价上方，坚决不买，耐心等待回调。若股票直接上涨飞走，坦然目送，寻找下一个标的。

### 铁律四：下单前必须人工核对券商真实账户数据
- **为什么**：命令行工具是辅助决策引擎，并不直接连接券商自动下单，无法感知您账户当前的实时冻结款项与真实持仓变化。
- **怎么做**：在券商 App 输入交易前，必须人工核对三要素：
  1. **证券代码与公司全称**（防止输错代码买成同音股票）；
  2. **账户可用现金余额**（确保扣款后不会出现资金缺口）；
  3. **实时五档买卖盘报价**（确认委托价处于合理区间）。

### 铁律五：风险自担，模型绝不承诺任何投资收益
- **为什么**：金融市场充满不确定性，宏观黑天鹅、行业政策变化、上市公司财务真实性等均超出数学模型的完全预测范围。
- **声明与原则**：
  1. **无保本保收益承诺**：SmartInvest 系统的所有测算、估值区间与分批挂单建议仅供量化研究与参考，**不构成任何明示或暗示的投资保证与收益承诺**。
  2. **独立决策与风险自负**：投资者必须具备完全民事行为能力，根据自身的风险承受能力独立做出最终投资决策，并自行承担全部交易后果与资金亏损风险。

## 一、 盘中决策的三大认知红线（关键概念辨析）

在开始使用任何量化分析或运行命令行命令之前，请个人投资者务必牢记以下三大核心概念的本质区别。混淆这些概念是造成交易失误的最常见原因：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      三大认知红线核心对照矩阵                           │
├───────────────────┬──────────────────────────┬──────────────────────────┤
│ 维度              │ 概念 A                   │ 概念 B                   │
├───────────────────┼──────────────────────────┼──────────────────────────┤
│ 1. 行情价格       │ Longbridge 盘中报价      │ 上一交易日收盘价         │
│                   │ (来源与分钟时间可核验)   │ (本地 SQLite 历史日线)   │
├───────────────────┼──────────────────────────┼──────────────────────────┤
│ 2. 资金口径       │ 账户总资产 (Total Equity)│ 可用现金 (Available Cash)│
│                   │ (股票市值 + 剩余现金)    │ (下单前另行核验支付约束) │
├───────────────────┼──────────────────────────┼──────────────────────────┤
│ 3. 指令属性       │ 触发条件 (If-Then 条件)  │ 立即买入建议 (Market Buy)│
│                   │ (回踩安全边际买点才执行) │ (绝非看到信号市价追入)   │
└───────────────────┴──────────────────────────┴──────────────────────────┘
```

### 1. Longbridge 盘中报价 vs 上一交易日收盘价

- **上一交易日收盘价（本地数据）**：
  SmartInvest 系统在本地 SQLite 数据库中存储的是每日盘后同步的日线行情数据（通常是昨日 15:00 收盘价）。该基准用于事前测算合理的估值区间与日线技术支撑位。
- **盘中行情（Longbridge OpenAPI）**：
  `stock size` 优先通过 Longbridge 官方 CLI 获取最新价，并用当日分时数据中的最新分钟时间
  校验新鲜度。终端会明确显示 `longbridge-openapi` 来源和报价时间。Longbridge 未安装、未登录
  、不可用或报价超过 15 分钟时，系统继续尝试腾讯、AKShare 和 Yahoo。只有时间校验通过的
  行情才参与执行判断；`longbridge auth status` 显示 `15-min Delay` 时不得将其称为实时行情。
- **券商盘口**：
  Longbridge 行情用于测算和条件判断，但不等于银河账户的买一/卖一与可用资金。正式下单前仍需
  在券商 App 核对盘口、已成交数量和可用现金。
- **🚨 核心红线**：
  **绝不能将本地历史收盘价直接当作当前能够立即成交的现价！**
  在盘中做出任何挂单决策前，必须打开手机券商 App 查看当前的实时真实买一/卖一价格。

### 2. 账户总资产 vs 可用现金

- **账户总资产（Total Capital / Equity）**：
  包含您账户内持有的**所有股票现有市值 + 现金余额**的总和。系统从配置文件 `stock-analysis.toml` 的 `[portfolio].cn_account_assets` 自动读取（若未配置且未通过参数指定则会报错，不再使用 10 万元默认值）。系统的风控模型（例如设定核心标的最大持仓 20%）是基于【账户总资产】测算该股票允许配置的目标金额上限。
- **可用现金（Available Cash）**：
  您当前证券账户中尚未买入任何资产、此时此刻**可以直接用来扣款下单的闲置资金**。可用现金是下单前由投资者在券商端另行核验的**支付约束**。
- **🚨 核心红线**：
  `--capital` 表示的是【账户总资产】，不是可用现金！
  系统计算出的建议买入金额（例如：总资产 50,000 元 × 目标上限 20% = 10,000 元）表示该标的建仓完毕后的**理想目标配置额度**。
  如果您的账户目前仅剩 5,000 元可用现金，**严禁通过借款、融资融券或透支去强行买满 10,000 元**；应在可用现金约束内合理下单或补充自有资金。

### 3. 触发条件 vs 立即买入建议

- **触发条件（Trigger Condition / If-Then 挂单点）**：
  系统在晨报或测算表中给出的“挂单价 / 触发价”，代表“**如果未来市场价格回踩到这个具有安全边际的点位，才构成合理的建仓条件**”。
- **立即买入建议（Immediate Market Buy）**：
  误以为一看到分析报告，就要在当前价格以市价单立刻全额买进。
- **🚨 核心红线**：
  **“进入分析池”绝不等于“现在立刻买入”！**
  如果标的当前市场价格高于第一档挂单价，现在的正确动作是**耐心等待价格回调**或**在券商 App 预埋条件单**，绝不可市价追高。

## 二、 实盘仓位精算器 stock size 安全使用范式

`stock size` 是专为实盘交易者设计的仓位与挂单测算工具。它能根据投资者的总资产规模、已有持仓与风险预算，自动计算出 3 个梯度的挂单价格、建议股数（精确向下取整至 100 股整数手）与逻辑失效参考线。

### 1. 自动读取配置与一键测算

如果您已经在 `stock-analysis.toml` 中配置了账户总资产与标的信息，只需直接输入证券代码：

```bash
# 语法：uv run stock size 证券代码
uv run stock size CN:601318
```

- **自动行为**：
  - **总资产读取**：自动从 `stock-analysis.toml` 的 `[portfolio].cn_account_assets` 读取账户总资产。**若配置文件中未提供该项，系统将直接报错退出，不再隐式回退至 100,000 元默认值**。
  - **持仓与参数读取**：自动读取 `[assets."CN:601318"]` 中的标的角色（`role = "core"` 核心资产通常配置 20% 上限，`satellite` 卫星资产通常配置 10% 上限）、已有持仓股数 `current_shares`（若已配置）、估值模型参数以及本地历史技术支撑位。

### 2. 使用 --capital 指定或覆盖账户总资产

当您需要临时调整参与测算的账户总资产基准时，可使用 `--capital` 参数：

```bash
# 示例 1：指定账户总资产为 51,546.80 元
uv run stock size CN:601318 --capital 51546.80

# 示例 2：指定总资产 100,000 元
uv run stock size CN:601318 --capital 100000
```

> [!NOTE]
> `--capital` 严格对应账户总资产（市值 + 现金）。请勿将可用现金作为 `--capital` 传入，否则会扭曲标的在全账户中的目标权重分配。可用现金应在报单前在券商 App 端单独核验。

### 3. 自动实时行情与离线覆盖参数

交易时间段内不需要手工输入价格：

```bash
# 自动获取 Longbridge 行情，临时指定已有持仓 300 股和总资产 51,546.80 元
uv run stock size CN:601318 --capital 51546.80 --held-shares 300

# 自定义目标仓位上限为 15%，单笔最大风险 1.5%
uv run stock size CN:601318 --capital 51546.80 --target-weight 0.15 --risk-budget 0.015
```

- **参数核心机制**：
  - `--price <价格>`：只用于离线复现和计算核对。人工输入价格没有来源时间，系统会明确标为
    “未由系统验证”并暂停执行判断，不能用它伪装实时行情。
  - `--held-shares <股数>`（或配置文件中的 `assets.<symbol>.current_shares`）：指定当前已持有的股数。
  - Longbridge 返回的盘中价**只覆盖执行价和触发状态判断**。系统计算的三档买点价格继续严格
    锚定已完成的日线分析基准，不使用盘中价重新计算技术/估值网格。
  - **仓位扣减与上限控制**：
    - 系统以盘中执行价估算已有仓位的当前市值（$\text{已有仓位市值} = \text{已有股数} \times \text{盘中现价}$）；
    - 从目标额度（$\text{目标额度} = \text{总资产} \times \text{目标比例}$）中扣除已有仓位市值，计算剩余可用买入额度；
    - **当已有仓位市值达到或超过目标上限时，剩余额度为 0，三档建议股数均为 0 股（0 手），系统提示不新增买入**。

### 4. 输出表格与关键字段逐项图解（以中国平安为例）

以**中国平安 (CN:601318)** 为例，设定账户总资产 51,546.80 元、已有 300 股、盘中价 57.10 元、目标上限 20%（对应目标额度 10,309.36 元）：
- 已有持仓市值：$300 \times 57.10 = 17,130.00\text{ 元}$；
- 当前仓位占比：$17,130.00 / 51,546.80 \approx 33.23\%$；
- 测算结果：当前仓位（33.23%）已超过目标上限（20%），剩余额度为 0.00 元，三档挂单均为 0 股，状态为不新增买入。

## 三、 盘中六大状态决策树：现在该做什么 / 不该做什么

在交易时间内，根据券商 App 呈现的**实时价格**与系统计算出的**三档挂单阶梯与失效参考线**，投资者将面临以下六种典型市场状态。请对照执行：

```
                           ┌───────────────────────────┐
                           │ 核对行情来源、时间与盘口  │
                           └─────────────┬─────────────┘
                                         │
         ┌───────────────────────────────┼───────────────────────────────┐
         ▼                               ▼                               ▼
  【现价 > 首笔价】              【现价 == 某档挂单价】            【现价 < 失效线】
  (状态 1: 溢价观望)             (状态 2, 3, 4: 触发分批)          (状态 5: 逻辑破位)
         │                               │                               │
  ▶ 严禁追高追涨                  ▶ 严格限价单买入对应手数        ▶ 取消加仓并核对条件
  ▶ 设置到价预警                  ▶ 扣除已有持仓不超上限          ▶ 自主决定风控应对
```

---

### 状态 1：高于首笔价（溢价观望区）

* **判定标准**：系统取得的新鲜盘中价高于表格中的“① 首笔底仓”挂单价格（即尚未进入日线安全边际买入区间）。
* **✅ 现在该做什么**：
  1. **保持耐心，空仓或持股观望**：严格遵守交易纪律。
  2. **设置预警/条件单**：在券商 App 中针对该标的设置到价预警，或预设一条“回踩触达买入限价条件单”。
* **❌ 现在绝对不该做什么**：
  1. **严禁市价追高**：绝不能因盘面短线拉升、害怕踏空（FOMO 情绪）而市价买入。
  2. **严禁自行上调买入价格**：买点锚定日线基准，不可盘中随意抬高建仓成本。
* **💡 风控提醒**：
  追高买入会直接侵蚀安全边际，使后续持仓陷入被动。

---

### 状态 2：达到首笔价（首笔底仓触发）

* **判定标准**：股价在盘中正常回调，触及或低于“① 首笔底仓”挂单价格。
* **✅ 现在该做什么**：
  1. **限价单委托**：打开券商 App，选择【普通限价买入】，填入首笔挂单价，数量按表格给出的【建议手数】（扣除已有持仓后）。
  2. **核对可用资金**：确认委托所需资金在券商账户当前的可用现金余额之内。
* **❌ 现在绝对不该做什么**：
  1. **严禁一次性打满全部预算（All-in）**：首笔底仓仅为基础配置，绝不可提前耗尽后续档位的资金。
  2. **严禁使用市价单买入**：必须使用限价单，避免盘口瞬间滑点造成不利成交。
* **💡 风控提醒**：
  首笔底仓的作用是建立跟踪仓位，后续档位保留了更低成本的加仓空间。

---

### 状态 3：达到第二档（强支撑回调加仓）

* **判定标准**：股价进一步下挫，触及“② 回调加仓”价格（近端强支撑区间上沿）。
* **✅ 现在该做什么**：
  1. **核对无突发基本面恶化**：简要查看公告与行业动态，确认无重大违法违规、业绩断崖式恶化等黑天鹅。
  2. **限价单买入第 2 笔**：在券商 App 中按第 2 档建议价格和建议手数下达限价买单。
* **❌ 现在绝对不该做什么**：
  1. **严禁因盘面恐慌而放弃执行**：若基本面未变，达到预定支撑位即属于计划内操作，不应受情绪干扰。
  2. **严禁超额加仓**：不可擅自把第 3 档的额度提前挪用。
* **💡 风控提醒**：
  分批建仓的核心在于平摊成本，需严格按照既定计划推进。

---

### 状态 4：达到第三档（极限价值底加仓）

* **判定标准**：市场出现深度调整，股价触及“③ 极限买点”价格（次级纵深支撑带或深度估值安全下沿）。
* **✅ 现在该做什么**：
  1. **执行最后一笔限价买入**：下达第 3 档建议手数的限价买单。
  2. **完成建仓闭环**：该标的阶梯计划已执行完毕，总持仓达到预设的目标上限比例。
* **❌ 现在绝对不该做什么**：
  1. **严禁继续追加第四笔、第五笔**：该标的的买入额度已用尽，不新增买入。
  2. **严禁加杠杆或借款补仓**：严禁动用非闲置资金或融资融券补仓。
* **💡 风控提醒**：
  三笔建仓完成后即应停止买入操作，等待市场修复或触发退出评估。

---

### 状态 5：跌破失效线（逻辑破位与风控评估）

* **判定标准**：股价跌破表格底部的“🛑 逻辑失效与止损参考线”。
* **✅ 现在该做什么**：
  1. **立即取消后续加仓计划**：撤销券商端尚未成交的所有买入委托与条件单。
  2. **核对确认条件与基本面**：观察是否满足连续收盘确认条件（如连续两个交易日有效收盘低于失效线），并审查持仓逻辑是否发生实质性破坏。
  3. **自主决策风控应对**：由投资者结合自身风险承受能力，理性决定是否通过限价单减仓、止损离场或调整策略。
* **❌ 现在绝对不该做什么**：
  1. **严禁逆势死扛并盲目倒金字塔加仓**：破位之后绝不可越跌越买。
  2. **严禁忽视风控预警信号**。
* **💡 风控提醒**：
  参考失效线是保护本金的预警红线，非自动执行的强制指令，需投资者人工复核并自主决策。

### 状态 6：报价过期或数据源获取失败（离线与异常处置）

* **判定标准**：运行 `stock size` 提示“没有可用行情缓存”或报错，或数据日期与实际交易日明显脱节。
* **✅ 现在该做什么**：
  1. **暂停依赖命令行决策**：立即以券商 App 真实行情数据为准。
  2. **检查并同步数据**：盘后或网络恢复时，运行数据同步命令：
     ```bash
     uv run stock sync CN:601318
     ```
  3. **运行环境诊断**：若持续异常，运行系统诊断工具：
     ```bash
     uv run stock doctor
     ```
* **❌ 现在绝对不该做什么**：
  1. **严禁依据过期或异常的数据盲目挂单**。
  2. **严禁在数据质量警告高危时强行开仓**。
* **💡 风控提醒**：
  数据失败时必须暂停操作，确保信息准确后再做决策。

## 四、 个人投资者实盘执行五大铁律

### 铁律一：严格使用限价单，坚决禁用市价单
- **逻辑**：A 股市场在集合竞价及盘中剧烈波动时，市价单极易遭遇流动性滑点损失。
- **执行**：所有买入与卖出委托，必须在券商 App 中使用**普通限价单**或**到价限价条件单**，精确填入具体数值。

### 铁律二：严格分批建仓与仓位扣减，拒绝一次性打满
- **逻辑**：无人能预测最低点，且必须考虑账户内已持有的股票仓位，避免单一标的风险过度集中。
- **执行**：系统自动扣除已有持仓市值；若已有仓位达到或超过目标上限，三档建议均为 0 股，坚决不新增买入；未达上限时严格按阶梯分批挂单。

### 铁律三：严格坚守不追涨，买点锚定日线基准
- **逻辑**：追涨是导致交易亏损的主要诱因，盘中追高会直接丧失安全边际。
- **执行**：现价高于第一档挂单价时坚决不买，买点严格锚定日线估值与技术支撑，不随盘中情绪上调买点。

### 铁律四：下单前必须人工核对券商真实可用现金与账户数据
- **逻辑**：命令行工具为辅助决策系统，不直连券商交易接口，无法感知账户实时资金与持仓变化。
- **执行**：下单前核对三要素：
  1. **证券代码与标的名称**（防输错代码）；
  2. **账户可用现金余额**（确保满足支付约束，不透支、不借贷）；
  3. **实盘买卖盘报价**（确认委托价格处于合理区间）。

### 铁律五：风险自担，模型绝不承诺任何投资收益
- **逻辑**：金融市场充满不确定性，宏观波动与偶发事件超出量化模型预测边界。
- **声明与原则**：
  1. **无保本保收益承诺**：SmartInvest 系统的所有测算、估值区间与分批挂单建议仅供研究与决策参考，**不构成任何投资保证与收益承诺**。
  2. **独立决策与风险自负**：参考失效线与买入建议非自动化指令，投资者须根据自身风险承受能力独立决策，并自行承担全部交易后果与资金风险。
